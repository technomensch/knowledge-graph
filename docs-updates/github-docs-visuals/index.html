Homepage visuals, UX improvements, and doc fixes

February 26, 2026

Initial documentation site improvements: homepage journey flow diagram, expanded scenarios, and accessibility fixes.

Homepage Visuals & UX​

  • Journey Flow Mermaid Diagram: Replaced bulleted scenarios with a narrative left-to-right flow.
  • Expanded Scenarios: Added trigger moments and future payoffs (including agile sprint retrospectives).
  • "About This Project" Repositioning: Moved project backstory to the bottom of the page in a collapsed info box.
  • "How It Works" Concrete Rewrite: Clarified markdown-based storage and absence of external database dependencies.
  • Feature Discoverability: Set the full feature list to be open by default.
  • Intro Sentence: Added a guiding sentence before the journey flow diagram.
  • Typography: Removed emdashes from descriptive text for a cleaner documentation style.

General Documentation Updates​

  • Universal Installer Clarification: Added details to GETTING-STARTED.md regarding behavioral expectations and terminal/file access requirements.
  • Fragment Links & Anchors: Fixed broken internal navigation links in COMMAND-GUIDE.md and NAVIGATION-INDEX.md.
  • Accessibility Fixes: Added accTitle and accDescr to all new diagrams for Section 508 compliance.
  • Typo Fix: Corrected missing space in index.md Outcome card.
