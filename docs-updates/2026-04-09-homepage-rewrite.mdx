---
title: 'Home page redesigned - clearer audience, context grid, demo GIF'
---

The KMGraph home page has been redesigned based on user feedback. The previous page didn't immediately answer who KMGraph is for or what it does - visitors had to read too far before the value was clear.

<!-- truncate -->

## What changed

**New banner** - updated to lead with the audience hook, the problem, and the solution in a single visual:
- *"Using an AI coding assistant? KMGraph is for you."*
- *"KMGraph remembers what you and your tools forget."*
- *"Lessons Learned. Decisions. Institutional Knowledge."*

**Context grid** - a 2×2 grid immediately answers "what does it bridge?": sessions, models, tools, and teammates.

**What it stores** - three plain-language bullets mapping directly to the tricolon: lessons learned, decisions, and institutional knowledge.

**Audience badges** - explicit audience callout: Developer · Vibe-Coder · Prompt Engineer · Open-Source Maintainer · Small Agile Team.

**Demo GIF** - `capture-lesson` demo now shown on the home page so visitors see the tool in action before being asked to install it.
