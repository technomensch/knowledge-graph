## Problem Summary

The `kg-recall` skill and `/kmgraph:recall` command both appear in Claude Code's slash command autocomplete, creating user confusion:

- **`kg-recall`** — internal auto-trigger skill (fires on keyword phrases like "have we done this before?")
- **`recall`** — user-invoked command (with explicit topic + flags: `--type`, `--format`, `--scope`, etc.)

Users cannot distinguish these in autocomplete, risking:
1. Direct invocation of the skill (bypassing the richer command interface)
2. Naming inconsistency: `kg-` prefix (MCP tool convention) rather than skill naming convention

**Solution:** Rename the skill to **`auto-recall`** (ENH-013 Option A). The `auto-` prefix signals "automatic/internal" and removes the conflict — only `/kmgraph:recall` appears as the user-facing command.
